# Guide Helper Mobile

Текущий мобильный клиент сознательно ограничен ролью `Android companion app`, а не дублирует весь web-клиент.

## Product Scope V1

Мобильный baseline:
- запись GPS-маршрута на Android;
- пауза, продолжение и завершение записи;
- локальный черновик маршрута;
- фото и текстовые заметки к точкам;
- настройка точек маршрута и времени участков;
- отправка локальных черновиков на сервер после авторизации;
- просмотр своих синхронизированных маршрутов.

Что намеренно **не входит** в Android V1:
- администрирование;
- публичный каталог всех маршрутов;
- социальные функции;
- AI-чат;
- управление версиями маршрута;
- редактирование серверных draft-версий;
- публикационные режимы и сложный share-workflow;
- паритет с web по всем экранам и настройкам.

## Почему Такой Scope

Самая дорогая часть mobile-разработки здесь — не UI, а:
- фоновой GPS-трекинг;
- разрешения Android;
- локальное хранение;
- восстановление черновика;
- очередь синхронизации.

Поэтому мобильный клиент рассматривается как полевое дополнение к основной системе:
- `web` — проектирование, публикация, каталог, администрирование;
- `mobile` — запись маршрута в пути и последующая синхронизация.

## Основные Команды

```bash
npm run typecheck
npm run android
npm run android:debug:install
npm run android:preview:build
npm run android:preview:install
```
