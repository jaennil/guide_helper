Пользователи и доступ

FR-01. Регистрация пользователя готово

Реализация:Auth Service, экран входа/регистрации.

Проверка:зарегистрировать пользователя по email и паролю.

FR-02. Авторизация пользователя готово

Реализация:Auth Service, JWT access/refresh tokens.

Проверка:войти и открыть профиль.

FR-03. Обновление токена готово

Реализация:refresh-token endpoint и клиентская обработка.

Проверка:сессия не должна падать сразу после истечения access token.

FR-04. Профиль пользователя готово

Реализация:страница профиля.

Проверка:email, имя, роль, язык, маршруты пользователя.

FR-05. Ролевая модель готово

Реализация:user, moderator, admin; protected admin routes.

Проверка:admin открывает админку, обычный user нет.

Маршруты

FR-06. Создание маршрута готово

Реализация:редактор карты и Routes Service.

Проверка:создать маршрут, добавить точки, сохранить.

FR-07. Редактирование маршрута готово

Реализация:редактор маршрута.

Проверка:изменить название, точки, категории, цвет линии, настройки меток.

FR-08. Удаление маршрута готово

Реализация:Routes Service, мои маршруты, admin routes.

Проверка:удалить свой маршрут или удалить через админку.

FR-09. Публичная ссылка готово

Реализация:share_token, shared route page.

Проверка:открыть /shared/{token} без авторизации.

FR-10. QR-код маршрута готово

Реализация:QR modal.

Проверка:открыть QR-код из share workflow.

FR-11. Встраиваемый виджет готово

Реализация:embed route page.

Проверка:открыть iframe/embed-представление.

FR-12. Статистика маршрута готово

Реализация:расстояние, высоты, время, сложность.

Проверка:построить маршрут и посмотреть статистику.
