# Пакет понимания проекта Guide Helper

Эта папка нужна не для сдачи как есть, а для подготовки к защите: быстро вспомнить, что сделано, зачем это сделано и как отвечать на вопросы.

Файлы:

- `01-project-overview.md` — короткий обзор проекта на 1-2 страницы.
- `03-roles-and-scenarios.md` — роли, сценарии и критические пути пользователей.
- `04-architecture.md` — архитектура простым языком: компоненты, данные, потоки.
- `05-requirements-traceability.md` — 37 функциональных требований: где реализовано и как проверять.
- `06-commission-questions.md` — вопросы комиссии и короткие устные ответы.
- `08-strong-screenshots.md` — какие скриншоты показывать и зачем.
