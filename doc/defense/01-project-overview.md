# 1. Краткий обзор проекта

## Что разрабатывается

Guide Helper — информационная система для создания, изменения, публикации и просмотра туристических маршрутов с геопривязанными фотографиями.

Главная идея: автор маршрута не просто рисует линию на карте, а формирует полноценный интерактивный маршрут: точки, фотографии, заметки, статистика, описание, публичная ссылка, QR-код, каталог и обратная связь от туристов.

## Для кого система

Основные пользователи:

- Гиды, инструкторы, авторы маршрутов.
- Туристы и участники экскурсий.
- Туристические организации.
- Администратор платформы.

## Какая проблема решается

У авторов маршрутов нет единого удобного инструмента, где можно одновременно:

- создать маршрут на карте;
- прикрепить фотографии к конкретным точкам;
- добавить комментарии и описания к точкам;
- автоматически обработать фотографии;
- получить публичную ссылку на готовый маршрут;
- использовать маршрут как витрину для потенциальных клиентов;
- дать туристам возможность искать, оценивать и комментировать маршруты.

Обычные карты решают только часть задачи. Спортивные приложения хорошо записывают треки, но не ориентированы на публикацию экскурсионного или туристического маршрута с мультимедийным содержанием.

## Главный практический результат

Разработана работающая система Guide Helper, которая позволяет автору создать интерактивный туристический маршрут с геопривязанными фотографиями и опубликовать его для туристов по ссылке, QR-коду или через каталог.

## Что считать уникальным преимуществом

Сильная формулировка:

Guide Helper объединяет в одном сценарии ручное проектирование маршрута, геопривязку фотографий к точкам, серверную обработку изображений, публичную интерактивную публикацию, социальные функции и AI-инструменты для помощи при создании маршрута.

## Что не надо говорить

Не стоит защищать проект как “ещё один CRUD”. CRUD там есть, но результат шире:

- работа с геоданными;
- маршрутизация и расчёт статистики;
- обработка медиафайлов;
- публикация интерактивного маршрута;
- асинхронные задачи;
- AI-инструменты;
- PWA/desktop/mobile-контур;
- администрирование и модерация.

## Что входит в систему

Web-клиент:

- редактор маршрута на карте;
- прикрепление фото и заметок к точкам;
- построение маршрута между точками;
- профиль высот, погода, сложность, расстояние;
- публикация маршрута;
- каталог маршрутов;
- комментарии, рейтинги, лайки, закладки;
- AI-ассистент;
- профиль пользователя;
- административная панель.

Backend:

- сервис аутентификации;
- сервис маршрутов;
- обработчик фотографий;
- сервис кеширования тайлов;
- сервис проксирования тайлов;
- интеграции с геокодингом, погодой, высотами, AI-провайдерами.

Инфраструктура:

- PostgreSQL;
- MinIO;
- NATS JetStream;
- Redis;
- Docker Compose;
- Kubernetes-манифесты;
- GitHub Actions;
- ArgoCD/кластерный деплой.

Мобильный клиент:

- Android companion app;
- запись GPS-маршрута;
- локальные черновики;
- синхронизация маршрута на сервер;
- фото и текстовые заметки к точкам.

## Как объяснить проект за 30 секунд

Я разработал Guide Helper — систему для гидов и туристов, которая позволяет создавать туристические маршруты с фотографиями, привязанными к конкретным точкам на карте. Гид может собрать маршрут после прохождения или экскурсии, добавить фото и заметки, автоматически получить статистику маршрута, опубликовать ссылку или QR-код и использовать маршрут как презентацию для клиентов. Туристы могут находить маршруты в каталоге, смотреть фотографии на карте, оставлять оценки и комментарии. Для поддержки этого реализованы web-клиент, backend на микросервисной архитектуре, обработка фото, AI-ассистент, админка и дополнительный Android-клиент для записи маршрута в полевых условиях.
