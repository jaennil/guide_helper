Почему микросервисы

Система разделена на сервисы, потому что разные части имеют разный характер нагрузки: быстрые операции профиля и авторизации, тяжёлая обработка фотографий, работа с маршрутами, кеширование тайлов, AI-запросы и внешние интеграции.

Клиенты

  • Web PWA / Desktop UI — основной интерфейс.
  • Android companion app — запись GPS-маршрута в поле.

Backend-сервисы

  • Auth Service — вход, JWT, роли.
  • Routes Service — маршруты, каталог, social, AI.
  • Photo Worker — обработка фото.
  • Tiles Service — прокси тайлов.
  • Cache Service — кеш тайлов.

Хранилища

  • PostgreSQL — пользователи, маршруты, комментарии, рейтинги.
  • MinIO — оригиналы фото и миниатюры.
  • NATS JetStream — очередь задач обработки фото.
  • Redis — кеш картографических тайлов.

Зачем AI

AI не заменяет ручной сценарий. Он помогает текстом построить маршрут, найти место или сгенерировать описание. Если AI недоступен, основной функционал остаётся рабочим.

Web vs Mobile

Web основной, потому что маршрут удобнее оформлять на большом экране. Mobile — дополнение для записи GPS-трека во время реального прохождения.
