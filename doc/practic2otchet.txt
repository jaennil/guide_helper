В ходе производственной практики я работал в команде поддержки продукта компании amoCRM в качестве backend-разработчика. Основной зоной ответственности были сервисы AmoJO (платформа обмена сообщениями с интеграциями во внешние мессенджеры), FILES (сервис управления файлами) и INBOX (сервис уведомлений).

Основная часть работы была связана с диагностикой и устранением ошибок в интеграциях с мессенджерами. Наибольший объём задач пришёлся на интеграцию с Instagram: я исправлял ошибки отправки сообщений и медиафайлов, устранял проблемы с авторизацией аккаунтов, исправлял дублирование исходящих сообщений, а также обеспечил корректную работу salesbot при ответе через Instagram. В рамках работы с Telegram я решил проблему отправки видеофайлов, которые приходили получателю как документ вместо видео, и реализовал генерацию превью для видеофайлов различных форматов. По интеграции с ВКонтакте исправлял ошибки отображения медиа и улучшал информативность сообщений об ошибках. В интеграции с Авито реализовал проверку актуальности входящих вебхуков по времени для предотвращения лишних повторных попыток обработки.

В сервисе FILES я работал над функциональностью правил автоматического удаления файлов — исправлял ошибки в логике удаления и добавлял корректную обработку регистра символов в типах файлов. В сервисе INBOX исправлял некорректную обработку HTTP-ошибок, из-за которой клиентам возвращался неинформативный код 500 вместо корректного ответа.

Помимо работы с интеграциями, я занимался улучшением основной платформы: добавил передачу поля source в API объединения сообщений, закрыл возможность отправки внутренних сообщений во внешние каналы, реализовал информативные сообщения об ошибках для пользователей, исправил обработку ошибок при транскрибации аудио. Также исправлял ошибки в документации API и приводил примеры запросов в соответствие с актуальным поведением системы.

За время практики я приобрёл опыт работы с высоконагруженными сервисами, взаимодействия с внешними API мессенджеров, отладки распределённых систем и работы в команде по методологии Kanban с использованием Jira.
