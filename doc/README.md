# Документация Guide Helper

Верхний уровень `doc/` хранит только тематические каталоги. Актуальные артефакты для защиты лежат в отдельных папках, старые черновики и большие локальные файлы убраны в архив.

## Актуальные материалы

- `latex/` — исходники и PDF выпускной квалификационной работы.
- `presentation/` — финальная презентация: `guide-helper-defense.pptx`, `guide-helper-defense.pdf`, speaker notes и шаблоны Политеха.
- `defense/` — пакет подготовки к защите: командный центр, устные формулы, стресс-вопросы, demo-flow, сверка формулировок.
- `diagrams/` — C4, ER и sequence-диаграммы с HTML-индексом.
- `e2e/` — E2E-отчёты и скриншоты проверок интерфейса.
- `screenshots/` — скриншоты интерфейса для ВКР и презентации.
- `survey/` — анкета, ответы, агрегаты и графики пользовательского опроса.
- `practice/` — материалы производственной и преддипломной практики.
- `demo/` — demo-сценарии и вспомогательные материалы для демонстрации.
- `references/` — методичка, критерии нормоконтроля и книга по тестированию.

## Архив

- `archive/2026-04-prep/` — старые аудиты, чеклисты и подготовительные заметки апреля 2026.
- `archive/project-drafts/` — ранние DOCX/Markdown-черновики темы, описания проекта и спецификации требований.
- `archive/bundles/` — zip-бандлы, которые были нужны для обмена или сдачи.
- `archive/local-media/` — локальные записи и большие временные файлы; каталог игнорируется git.
