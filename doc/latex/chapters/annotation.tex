Дубровских Никита Евгеньевич. Разработка информационной системы для создания
туристических маршрутов с геопривязанными фотографиями и интерактивным шерингом
на основе микросервисной архитектуры. Выпускная квалификационная работа.
Направление подготовки 09.03.04 «Программная инженерия». ---
Научный руководитель: старший преподаватель Васильев Д.\,Б. --- 2026.

\vspace{10pt}

Работа посвящена разработке информационной системы Guide Helper, предназначенной
для создания туристических маршрутов с геопривязанными фотографиями и интерактивным
шерингом в сети Интернет.

Цель работы --- разработать информационную систему, позволяющую гидам и инструкторам
создавать туристические маршруты с фотографиями, привязанными к точкам маршрута,
автоматически обрабатывать медиафайлы на сервере и публиковать готовые маршруты
по уникальным ссылкам.

Объект исследования --- процесс создания и распространения геопространственных
туристических маршрутов с мультимедийным контентом. Предмет исследования ---
методы построения распределённых микросервисных информационных систем и алгоритмы
обработки геопространственных данных.

В первой главе проведён анализ предметной области цифрового туризма, сравнительный
анализ пяти конкурирующих сервисов, сформулированы функциональные и нефункциональные
требования, спроектированы архитектура системы и схема базы данных из одиннадцати
таблиц. Во второй главе описана реализация пяти микросервисов (аутентификация,
маршруты, кеш тайлов, ИИ-ассистент, обработка фотографий), клиентского
React-приложения и инфраструктуры Kubernetes с CI/CD-пайплайном. В третьей главе
представлены результаты модульного и функционального тестирования, анализ
производительности API-эндпоинтов, подтверждено соответствие нефункциональным
требованиям.

В результате работы реализовано 32 из 37 функциональных требований (86\%), разработано
115 модульных тестов, среднее время отклика API на 95-м перцентиле составило менее
80~мс при нагрузке 100 одновременных запросов.
