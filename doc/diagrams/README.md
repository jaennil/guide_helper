# Диаграммы Guide Helper

Единая точка просмотра: `index.html`.

Содержимое:

- `images/` — SVG-версии диаграмм для просмотра в браузере и вставки в документы.
- `source/` — исходники PlantUML и Draw.io для редактирования.

Диаграммы:

- C4 Level 1: контекст системы.
- C4 Level 2: контейнеры системы.
- C4 Level 3: сервис маршрутов.
- ER-диаграмма базы данных.
- Sequence-диаграмма обработки фотографии.
