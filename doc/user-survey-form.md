# Анкета Для Потенциальных Пользователей Guide Helper

## Формат

- Подходит для `Google Forms` и `Яндекс Форм`.
- Логика анкеты: общий блок + короткая ветка для автора маршрутов и короткая ветка для участника маршрутов.
- Цель: обосновать актуальность темы ВКР, подтвердить потребности целевой аудитории и собрать аргументы для требований к системе.

## Название формы

`Опрос потенциальных пользователей системы туристических маршрутов Guide Helper`

## Описание формы

`Опрос проводится в рамках выпускной квалификационной работы, посвящённой разработке информационной системы для создания и публикации туристических маршрутов с геопривязанными фотографиями. Цель опроса — выявить потребности пользователей, проблемы существующих решений и определить наиболее значимые функции системы. Опрос анонимный, результаты будут использоваться только в обобщённом виде в аналитической части ВКР.`

## Подсказки По Настройке Формы

- Сделать обязательными вопросы `1–17`.
- Вопросы `18–22` и `23–25` выводить через условную логику по ответу на вопрос `4`.
- Сбор email отключить.
- Разрешить только один ответ с одного устройства не обязательно.
- Перемешивание вариантов отключить, чтобы результаты были сопоставимы.

## Как Использовать Результаты В Дипломе

- Описать анкетирование как метод выявления потребностей целевой аудитории.
- В аналитической главе сослаться на результаты как на эмпирическое подтверждение актуальности функций.
- Для диплома особенно значимы группы ответов по вопросам `8–17` и `18–25`, так как они обосновывают:
  - необходимость привязки фото и заметок к точкам маршрута;
  - востребованность публикации маршрутов по ссылке;
  - значимость офлайн-доступа;
  - проблемы со стабильностью интернета и GPS;
  - перспективность сценария автоматической записи фактического маршрута.
